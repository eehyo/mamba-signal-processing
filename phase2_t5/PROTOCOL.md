# Phase 2 T5 분류 검증 실행과 최종 평가 절차

이 문서는 현재 학습·검증 설정과 공식 테스트 평가 전 확정할 항목을 기록한다.

| 항목 | 재현 설정 |
| --- | --- |
| 데이터 | 공식 Fashion-MNIST 학습 60,000장을 클래스 비율을 유지해 학습 48,000장·검증 12,000장으로 분할한다. 분할 seed는 42이며 각 조건의 순서가 보존된 이미지 인덱스를 `split.json`에 기록한다. |
| 주 비교 조건 | Axis-aligned (Raster), Snake, Random, Blockwise (2×2), Spiral. Column은 방향별 참고로 보관한다. |
| 고정 Random 순열 | NumPy PCG64 seed 42로 196개 위치의 단일 순열을 생성한다. 동일한 순열을 학습·검증·최종 평가의 모든 이미지에 적용한다. 이미지별, epoch별, 모델 seed별로 다시 섞지 않는다. 분석에 저장된 순열과 학습 코드가 생성하는 순열의 일치를 확인했다. |
| 학습 순서와 배치 | 조건마다 동일한 학습·검증 인덱스를 같은 순서로 제공한다. 대응 seed마다 PyTorch DataLoader에 별도 generator를 같은 seed로 초기화해 epoch별 학습 이미지 순서와 배치 구성을 맞춘다. 모델 seed는 모든 조건에서 0·1·2이며 배치 크기 64, 로더 워커 0을 공통 적용한다. 검증은 섞지 않는다. |
| Anti-aliasing | 실행 스크립트의 `--image_filter t5_bilinear`가 28×28 uint8을 [0,1] float32로 변환하고, 각 축에서 삼각형 저역통과 필터 `[1,3,3,1]/8`을 적용한 후 2배 간격으로 샘플링한다. 경계의 필터 가중치는 유효 픽셀에 맞춰 재정규화한다. 출력은 14×14이며 pixel mode에서 196×1이다. 이후 표준화에는 해당 학습 split에서만 추정한 스칼라 평균·표준편차를 적용한다. |
| Spiral | 0부터 세는 (행, 열) 기준으로 중앙 2×2의 왼쪽 위 (6,6)에서 시작한다. 오른쪽 → 아래 → 왼쪽 → 위를 반복하며 이동 길이는 1,1,2,2,3,3,…이다. 196개 위치를 각각 한 번씩 방문한다. |
| 공통 모델·최적화 | 선택적 Mamba 2층, `d_model=32`, `d_state=16`, `d_conv=4`, seed당 20 epoch. AdamW 학습률 0.001, 가중치 감쇠 0.01. 1차원 파라미터와 `A_log`에는 감쇠 0을 적용한다. Cross-entropy와 gradient norm clipping 1.0을 사용한다. |
| 검증 산출물 | seed별로 검증 macro-F1이 최대인 epoch의 체크포인트를 저장한다. 동률이면 먼저 도달한 epoch를 유지한다. 조건별 accuracy·macro-F1은 seed별 값과 평균·표본 표준편차를 기록하며, 혼동행렬은 행이 정답이고 열이 예측이다. |

## 공식 테스트 평가

현재 분류 실행은 공식 학습 파일만 읽어 학습과 검증을 수행한다. 앞서 생성한 테스트 Column PSD는 탐색적 참고로 기록되어 있다. 최종 평가에 앞서 팀이 조건·seed·체크포인트·전처리·지표·집계 규칙과 CNN baseline 설정을 별도 문서로 확정한다. 이후 동일한 설정으로 공식 테스트셋을 평가한다. 공식 테스트 지표를 보고 모델이나 분석 설정을 바꾸지 않는다. `mamba_starter/evaluate.py --split test`는 비어 있지 않은 `--final_protocol` 파일을 요구하고 해시를 결과에 기록한다.

## 신호 분석과 성능 연결

[인계 표](HANDOFF.md)의 다섯 조건은 동일한 공식 학습 이미지 60,000장과 동일한 분석 설정으로 비교했다. 성능 결과가 준비되면 조건을 키로 평균 좌표 이동 거리, 평균 절대 픽셀값 차이, 픽셀 PSD의 주파수와 크기, 경로 이동 성분 PSD·lag별 반복 지표를 연결한다. 각 조건의 accuracy·macro-F1은 3개 seed의 평균과 표준편차를 기록하고, 조건 간 비교에서는 같은 seed의 값을 대응시킨다. 픽셀 PSD의 최대 bin 하나만으로 주기성의 강도를 판단하거나 다섯 조건의 관계를 인과 효과로 해석하지 않는다.

최종 발표와 보고서에는 Mamba의 입력 의존적 상태 갱신을 설명한다. 각 픽셀 토큰을 투영한 뒤 짧은 causal convolution으로 스캔상 이웃 정보를 섞는다. 선택적 상태공간 모델에서는 입력에서 계산한 이산화 간격과 상태 입력·출력 계수가 토큰마다 달라져, 이전 상태를 얼마나 유지하고 어떤 입력을 반영할지 조절한다. 실험의 스캔 순서는 이웃 토큰과 상태 갱신의 입력을 함께 바꾼다.
