# Phase 2 Part 04 Mamba final test protocol

Fixed before classifier or convolution-response evaluation on the official test split. Scope is the Mamba kernel-width experiment in Part 04 of the presentation. The team-wide CNN baseline is a separate comparison.

- Evaluate all 30 existing checkpoints exactly once as a final evaluation round. Use Raster, Snake, Random, Blockwise and Spiral at widths 4 and 1, with model seeds 0, 1 and 2. For each condition use the existing `best.pt` selected by highest validation macro-F1, with the earliest epoch breaking ties. Use the checkpoint SHA-256 values in [width 4](../../checkpoints/manifest.json) and [width 1](../../checkpoints-dconv1/manifest.json). The model and training choices are fixed by the earlier validation experiment.
- Use the 10,000 official Fashion-MNIST test images and labels in their original order. The gzip MD5 values are `bef4ecab320f06d8554ea6380940ec79` and `bb300cfdad3c16e7a12a480ee83cd310`. Keep the checkpoint's 14×14 `t5_bilinear` pixel-mode preprocessing, scan and fixed Random permutation seed 42, training-only standardization, and model settings. Use FP32 CPU inference at the checkpoint batch size (64) with the repository evaluator and no test-time adaptation.
- Compute accuracy and macro-F1 over all ten labels, and retain the 10×10 confusion matrix for each checkpoint (true labels in rows, predicted labels in columns). Present the mean and sample standard deviation across the three seeds for each scan and width. Calculate width-4 minus width-1 macro-F1 and Snake minus Random within the same seed; round only after subtraction and aggregation. Test the existing prediction that reducing the width narrows the Snake–Random gap.
- Retain the presentation's prespecified class example. Compute Shirt F1 (class 6) per seed as twice its true positives divided by the sum of its true and predicted counts. Report seed means for Snake and Random at both widths, and report Random's mean Shirt→Pullover (class 2) error counts over seeds. Round counts to the nearest whole number for presentation.
- Repeat the existing first-block convolution-response probe on the same 10,000 test inputs and 30 frozen checkpoints. Before activation, compare each original depthwise convolution output to the output with its previous three projected tokens replaced by the current projected token. Discard positions 0–2 and pool squared differences and squared original outputs over all test images, retained positions and expanded channels. Report 100 times the square root of the ratio of the two sums as seed mean ± sample standard deviation. The original train-based boundary analysis and the earlier exploratory test Column PSD are outside this test evaluation.
- Classification can be reproduced with `python mamba_starter/evaluate.py --checkpoint CHECKPOINT --data_root OFFICIAL_IDX_DIRECTORY --split test --final_protocol phase2_t5/results/mamba-final-test/PROTOCOL.md --device cpu --threads 1 --out OUTPUT.json` for each frozen checkpoint. The response probe uses batch size 128 and the formula implemented in [the validation probe](../conv-context-validation/probe.py).
